# Lume dialog illustrations

Generated with the built-in image generation tool, using `assets/lumeview-cat.webp` as the character reference. Exported to 512 × 512 WebP at quality 75, retaining transparent alpha.

Shared prompt: the same cream-white Lume kitten, turquoise anime eyes, peach ears and warm brown outlines; simple polished chibi illustration, readable at small sizes; one functional prop, transparent background, no lettering or watermark.

- `lume-delete.webp`: Lume placing a small image document in a recycling bin, with a concerned expression.
- `lume-save.webp`: Lume hugging a teal floppy disk and raising a paw.
- `lume-rename.webp`: Lume holding a pencil and a blank file-name tag.
- `lume-shortcuts.webp`: Lume peeking over a teal keyboard with blank cream keycaps.

Displayed at 256 × 256 logical pixels at the upper right of the Delete, Save and Rename dialogs. In Shortcuts, the illustration overlays the right side of the scrolling content immediately after the Page Down / Page Up description, without reserving vertical space or displacing the following text. The full 512 × 512 textures retain sharpness on high-DPI displays. Embedded textures are decoded and cached only when the corresponding dialog first opens.

- `lume-preferences.webp`: new Preferences artwork, generated with the built-in image tool using the Save illustration as style reference. Prompt: the same cream-white Lume kitten with turquoise eyes, sitting and holding a teal settings cogwheel with a small adjustment-slider motif, matching chibi style, transparent background, no text. Exported as 512 × 512 WebP at quality 75. Applied at the upper right of the Preferences dialog at 256 × 256 logical pixels, with the same lazy texture cache as the other dialog artwork.
