Installer error codes

This page documents errors returned by LumeView's Windows EXE installer, version 0.29.0 and later. Microsoft Store silent installation uses /S.

1603 — Installation failed

The installer could not complete installation. Possible causes include insufficient permissions, inaccessible files or folders, or an extraction or registration failure.

Close LumeView, ensure the destination folder is writable and that enough disk space is available, then retry. If the problem persists, report the code and relevant error details through the support link below. Do not include personal images or sensitive information in public reports.

1001 — LumeView is running

The installed application is open and cannot safely be updated. Close all LumeView windows, then retry installation. Your images are not deleted by this error.

87 — Invalid installer parameters

The installer received an unsupported argument or an invalid argument value. For Microsoft Store installation, use /S as the silent installation parameter.

Interactive language options are --lang=en, --lang=pt, --lang=es and --lang=fr. If installing manually, run the installer without additional arguments or with /S.

Successful installation returns 0. These error codes do not indicate success.
